## 🛠 Maintenance Tips

- **Commit regularly.** When you update a project, push the change to GitHub the same day. A profile with recent commits looks alive; one with no commits for 6 months looks abandoned.
- **Keep the README in sync with the project.** If you add a new file to a repo, mention it in the README. A README that lists files that don't exist (or omits files that do) is worse than no README.
- **Star repositories you learn from.** Your starred list shows what you're studying — it's a passive signal of your interests. Employers look at this.
- **Update the *Currently Learning* badges every few months.** As you finish learning PLCs or AutoCAD, replace those badges with the next thing. A current "currently learning" section shows you're actively growing.
- **Add new repos over time.** Each new project gets the same README pattern as the existing ones. Consistency across the portfolio is what makes it look professional.

## ❓ Troubleshooting

| Problem | Fix |
|---|---|
| README shows raw markdown, not rendered | Make sure the file is named exactly `README.md` (capital letters, .md extension). |
| Badge shows broken image | Check the URL — copy-paste it into a browser; if it 404s, find a replacement at https://shields.io. |
| Wave banner doesn't load | capsule-render.vercel.app may be temporarily down. Refresh, or replace with a local image (see Step 8). |
| GitHub stats card shows zeros | The stats card needs your account to have some activity. If you have very few commits, it'll just show zeros — that's fine, it will fill in over time. |
| Pinned repo not showing | Make sure the repo is **public**. Private repos don't show on a public profile. |
| Old README content still showing | Hard refresh the page (Ctrl+Shift+R) — GitHub sometimes caches. |
